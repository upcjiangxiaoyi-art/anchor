# 小锚（聊天快照）

给 SillyTavern 用的防丢楼扩展。在 1.19.0 上测试通过。当前版本 1.2.9。由 Claude（Anthropic）和江一起做的。

## 它做什么

1. **守门**：酒馆读取聊天失败时，会把开场白当成新聊天存回去，盖掉原存档。小锚在读取失败后暂停这个聊天的保存，弹窗让你点「重新读取」。
2. **快照**：发消息、收到回复、编辑、删除之后，把屏幕上的聊天存一份到浏览器里。逐楼去重，几百楼的聊天留几十份也只占一份多一点的空间。
3. **掉楼提醒**：打开聊天时如果比上次快照少楼，自动锁住掉楼前那份并提示。
4. **补存**：保存到服务器失败时自动重试三次，并把服务器返回的错误记在「记录」里。
5. **大聊天保存时压缩**：保存请求超过 4 MB 就由小锚 gzip 后再发。酒馆自己只压 8 MB 以下的，几十 MB 的聊天裸着发很容易撞上反向代理的大小限制（nginx 默认 50m，报 413）。服务器不认压缩会自动改回原样发。

## 安装

把整个文件夹放进酒馆的 `data/<用户名>/extensions/`（或 `public/scripts/extensions/third-party/`），刷新页面。
也可以传到自己的 Git 仓库，用酒馆的「安装扩展」填仓库地址。

装好后请停用旧的「聊天记录快速恢复」插件。

## 使用

输入框旁的魔法棒菜单 →「小锚快照」。

- **恢复 → 覆盖当前聊天**：文件名不变；覆盖前会把现在的内容另存一份锁定快照。
- **恢复 → 恢复成新聊天**：走酒馆自带的导入，不动任何现有聊天。
- **导出**：存成 .jsonl 文件，可以用酒馆的「导入聊天」读回来。
- **锁**：锁定的快照不会被自动清理。
- **改了什么**：楼数没变也会多出快照，因为内容变了（换 swipe、编辑、脚本改了变量，或者酒馆自己记的 token 数、时间戳）。快照旁边会写「改了第 N 楼」或「只有聊天设置变了」，点一下能看到具体是哪些字段。
- **体检**：「当前」页点「体检」，在内存里把这个聊天按字段称一遍重：整份多大、压缩后约多大、什么占地方、最重的几楼。楼数不是问题，每楼的重量才是——别的扩展写进楼里的数据往往是大头，报告可以一键复制发给那个扩展的作者。
- **瘦身**：体检报告里点「瘦身…」。最近 50 楼不动，只给更早的楼卸包袱：酒馆给每条回复多存的那份和正文一模一样的 swipe 副本、老楼的思维链（默认勾），老楼里没被选中的备选回复（默认不勾）。注意酒馆重新显示到某一楼时会给它补回那份副本并随下次保存写回，所以副本这项只对平时不翻到的老楼有效。别的扩展写进楼里的数据不碰。开始前自动存一份锁定快照「瘦身前」，后悔可以恢复。
- **忽略字段**：有的扩展会隔几分钟往消息里写自己的记账信息（比如图片扩展的 `extra.stImageAtelier`），每次都会多一份快照。在弹窗里点「以后忽略」，或在「设置」里填上字段名，这些字段单独变化时就不再存快照。真要存的时候仍然存完整内容。

## 从服务器备份里捞

酒馆自己会在服务器上给每个角色留最近 50 份备份（`data/<用户>/backups/`）。以前要进宝塔或 1Panel 一个个翻，现在打开小锚 →「服务器」就能看到：按角色分好组，每份标出楼数，楼数突然掉一半以上的地方会标「掉楼前」，点「恢复成新聊天」即可。需要酒馆 1.17 或更新。

备份多的时候（几百份、几个 GB）这一页会慢：酒馆要把服务器上每一份备份都读一遍才能列出来。读取在后台进行，期间可以先去别的页，读完会自动显示。读到的列表会记在这台设备上，下次打开直接显示，点「刷新」才重新读。

如果一直是「HTTP 504」或超时，说明反向代理（宝塔 / 1Panel / 云平台）等不到酒馆就放弃了，备份目录太大。小锚改不了服务器，要在服务器上处理：
1. 文件管理里打开 `酒馆/data/<用户>/backups/`，按时间排序，把旧的 `chat_*.jsonl` 删掉一批（只是备份，不影响聊天本身）。
2. `config.yaml` 里把 `backups.common.numberOfBackups` 从 50 改成 10，`backups.chat.maxTotalBackups` 从 -1 改成 200，重启酒馆，然后随便发一条消息：酒馆会在这次保存时自动把目录裁到 200 份，以后也不会再长大。做了这步第 1 步可以不做。
3. 反代配置里把 `proxy_read_timeout` 加到 300 秒。
点「再试一次」前先等两分钟：代理放弃了，酒馆可能还在读上一次的。

## 从旧插件捞备份

如果这台设备上装过「聊天记录快速恢复」，它存的备份还在浏览器里。打开小锚 →「全部聊天」，最上面会列出来。先点「导出文件」存一份，再点「导入成新聊天」。

## 保留规则

最近 12 份一定保留；更早的，24 小时内每小时留 1 份，7 天内每天留 1 份。都可以在「设置」里改。

## 要知道的限制

- 快照存在**这台设备的浏览器**里。换设备、清除网站数据、卸载 App 后就没有了。重要的聊天请导出。
- 「守门」和「补存」是通过包一层 `fetch` 实现的，只看 `/api/chats/get`、`/api/chats/save` 和群聊对应的两个地址，其它请求原样放行。
